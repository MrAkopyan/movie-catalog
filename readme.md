## 1. Предметная область
Каталог фильмов онлайн-кинотеатра. Приложение позволяет просматривать список фильмов, добавлять новые, редактировать и удалять существующие записи. Данные хранятся в реляционной базе данных.

## 2. Структура базы данных и ER-модель
В базе данных реализованы две связанные таблицы:
- `genres` (жанры) — справочник жанров.
- `movies` (фильмы) — основная сущность каталога.

**Связь:** Один-ко-Многим (1:N). Один жанр может содержать множество фильмов, но каждый фильм относится ровно к одному жанру.

**Первичные ключи (PK):** `genres.id`, `movies.id`.
**Внешний ключ (FK):** `movies.genre_id` ссылается на `genres.id`.

### ER-диаграмма
```mermaid
erDiagram
